## 📋 Sobre o Projeto
Uma aplicação web (Single Page Application) para disputas de Jogo da Velha. O projeto foi desenvolvido como requisito acadêmico, focado em usabilidade e aplicando a identidade visual da Universidade de Fortaleza (UNIFOR).

## 🚀 Como Executar Localmente
Como a aplicação foi construída utilizando HTML, CSS e JavaScript puros em um arquivo único, não é necessária nenhuma instalação ou configuração de servidor.
1. Clone este repositório: `git clone https://github.com/daniellobo-ops/jogo-da-velha-unifor.git`
2. Abra a pasta `src`
3. Dê um duplo clique no arquivo `index.html` para abri-lo em qualquer navegador de internet.
